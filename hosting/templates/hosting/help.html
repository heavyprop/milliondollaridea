Secure Hosting / Getting started

Files for your conversations.

Share the examples, documents, and project files behind your feed posts.

01

Put your files in a folder

A hosting project is a folder of files you share through the site. Use it for a code example, a PDF that supports an explanation, or the files someone needs to follow your work.

For example

A post explaining a Python script could link to a project containing the script, a README, and example data.

02

Publish your project

Safe is the terminal tool that uploads your folder. Connect it to your account using the setup page, then run this command on your computer.

{% include "threads/partials/post_content.html" with blocks=publish_blocks %}

Replace ./my-project with your folder's path. Its name becomes the project name, listed under the account you used to sign into Safe.

Updating your files

Run the same command again to replace the project. Files you leave out of the folder are removed from the current upload. Previous versions aren't available to browse.

03

Link it in your feed post

Open your project in Secure Hosting and copy its address from your browser. Paste that link into a feed post so readers can open the files alongside your explanation.

Show a particular file

Click a file and copy that page's address to link directly to its preview. A project link is better for ongoing updates: publishing again replaces the individual file links.

Projects are visible to signed-in accounts by default. Only the owner and people given editing access can replace their files.

04

Download a copy

What readers can open

Code and text

Open small UTF-8 text files in the browser. Code keeps its formatting and has a copy button.

Markdown

Uses the same text and fenced-code formatting as feed posts.

PDFs, images, and archives

Appear in the file list. Download the project with Safe to open these on your computer.

Before you publish

Up to 25 MiB compressed, 100 MiB unpacked, and 2,000 ZIP entries. Browser text previews are limited to 256 KiB.

Keep passwords and API keys out of your project. Uploaded code is displayed as text; the website doesn't run it.
